Installation Instructions

Chrome / Edge / Brave

  1. Download the ZIP file above
  2. Extract the ZIP to a folder you'll keep (e.g. PCM-Compass)
  3. Open your browser and go to chrome://extensions (or edge://extensions)
  4. Enable Developer mode (toggle in top-right)
  5. Click Load unpacked
  6. Select the extracted PCM-Compass folder
  7. The extension icon appears in your toolbar — pin it for easy access

Opera

  1. Download the ZIP file above
  2. Extract the ZIP to a folder you'll keep
  3. Open Opera and go to opera://extensions
  4. Enable Developer mode
  5. Click Load unpacked and select the extracted folder

Firefox

  1. Download the ZIP file above
  2. Extract the ZIP to a folder you'll keep
  3. Open Firefox and go to about:debugging#/runtime/this-firefox
  4. Click Load Temporary Add-on...
  5. Select any file inside the extracted folder (e.g. manifest.json)
  6. Note: Firefox temporary add-ons are removed when Firefox closes. To keep it, use Firefox Developer Edition or configure auto-loading.
After installing: Click the extension icon in your toolbar. The extension opens IDM, Grouper, and Printer Search pages directly — no login dialogs needed (your browser session handles authentication).
