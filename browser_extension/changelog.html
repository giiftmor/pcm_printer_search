PCM Compass — What's New

What changed in each version of the PCM Compass extension.

v2.3.3 2026-08-04

  • Fix Fixed a crash when opening/searching the app from the popup (invalid tab address pattern)
  • New Printer hostnames can be typed with or without the "P-" prefix — it is added automatically

v2.3.2 2026-08-04

  • New Grouper group presets now open the exact group pages (with their full links) — no more typing group names
  • New Settings (⚙) now works — set or reset the app address right in the popup
  • New An update banner appears when the extension needs a one-time reload after an update
  • New "Open app" moved to the popup footer

v2.3.1 2026-08-04

  • Fix Fixed popup crashing on open (missing file now ships with the extension)
  • New Footer shows the installed version and this "What's New" page

v2.3.0 2026-08-04

  • New Grouper Groups section — open common groups (Papercut staff, Azure staff/students, MS licences, Acrobat) with one click, or type any group name

v2.2.1 2026-08-03

  • Fix Updated the app address so the extension connects to the current server

v2.2.0 2026-08-03

  • New Open SVCP button — opens the printer's web interface straight from a printer hostname

v2.1.0 2026-07-21

  • New IDM, Grouper, and printer search reuse an open tab instead of opening duplicates
  • New Quick links work even when offline
